## 完整性检查

- [ ] 证券身份、交易所、类型、币种和价格时间已核验。
- [ ] 3—5 条核心论点可证伪且包含最强反证。
- [ ] M4/M10 的外部约束已经进入 M1/M2/M7。
- [ ] M3 催化剂只通过模型变量、实现时点或概率生效。
- [ ] M6 只影响执行，不替代内在价值。
- [ ] M8 的现金股息只计一次；回购通过股数体现。
- [ ] M9 精度与期权链同步程度匹配。
- [ ] M7 已回写风险而非仅列风险。
- [ ] M2-B 使用风险调整后的输入。

## 数值检查

- [ ] 三情景概率恰为 100%。
- [ ] 每个 `TR_s`、`ETR`、`EU`、`ED`、`PCR`、`SL`、`H` 可复算。
- [ ] 目标价上/下行、股息率、派息率、FCF 与每股单位一致。
- [ ] EV 到股权价值、稀释股数、拆股、ADR 和币种一致。
- [ ] 期权最大收益、最大损失和盈亏平衡与逐腿报价一致。
- [ ] 评级来自 `scripts/decision_math.py` 或完全相同的机械规则。

## 证据检查

- [ ] 所有改变评级的事实有 Source ID 和日期。
- [ ] 共识有提供方和快照日期。
- [ ] 估计给公式，假设给理由。
- [ ] 搜索摘要未作为最终证据。
- [ ] 管理层长期判断已外部验证或标未验证。
- [ ] 冲突证据已披露。
- [ ] ECS 只使用允许的离散分值。

## 自动失败

出现任一项，把结果标为“不合格草稿/暂不评级”：

1. 当前价或价格日期不可核验；
2. 概率不等于 100%；
3. 目标价无法从经营与估值假设桥接；
4. 股息、回购或催化剂被双重计价；
5. 引用不支持对应关键主张；
6. 把不可得回测、共识、资金流、技术指标或期权链写成已验证事实；
7. 隐藏关键来源冲突；
8. 评级与机械门槛不一致；
9. 计算错误未解决；
10. 证券身份、币种或股本口径无法确认。

## 增量更新

保留上次分析日期、评级、ETR、SL 与 ECS。逐项输出：

```text
新事实与 Source ID
旧值 → 新值 → 变化原因
受影响 Claim
受影响模型变量/情景概率
对 ETR / SL / ECS / 评级的影响
```

只更新被新事实击中的节点。评级未变化时，报告距离下一门槛的差值。
